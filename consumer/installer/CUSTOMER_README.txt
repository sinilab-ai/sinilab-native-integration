SINILAB.AI PLUGIN LICENSING — CUSTOMER READ ME

This shared Windows application manages licences for native C++ plugins
integrated with the Sinilab.ai Native Licensing SDK.

INSTALLATION
1. Run the Sinilab.ai Plugin Licensing setup EXE on Windows.
2. Follow the installer. Administrator permission may be requested.
3. Install your purchased collaborator plugin using its separate installer.
4. Launch Sinilab.ai Plugin Licensing from the Start Menu.
5. Select your installed product, enter the licence key supplied with
   your purchase and choose Activate licence.
6. Reopen your plugin after successful activation.

The application lists products that have registered themselves with the
Sinilab.ai native plugin registry. If a product is missing, ensure its
collaborator installer has correctly registered it.

LICENSING
An internet connection is needed for initial activation. The licensing
system uses a 15-minute validation cache and permits up to 24 hours of
offline operation after successful validation when the network is unavailable.
An authoritative release or revocation prevents further licensed operation.

UPDATES AND UNINSTALL
Updating or uninstalling the shared licensing application does not
intentionally remove the local licence activation data. Do not manually
remove activation records. Uninstalling a collaborator plugin must not
uninstall this shared licensing application.

This application does not install your purchased collaborator plugin.
For product-specific support, contact the product's collaborator.
