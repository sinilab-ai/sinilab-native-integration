# Publishing this candidate

**Do not publish without reviewing `RESOURCE_STATUS.md` and the technical content.**

1. Extract the ZIP locally and inspect the directory tree.
2. Compare the candidate README against the README already committed on GitHub; the included version adds links and a candidate status banner.
3. When approved, upload the folder contents using Git (recommended for nested folders). GitHub's web upload can also upload multiple files, but confirm paths and review the diff.
4. Suggested commit: `Add native integration documentation candidate v0.2`.
5. Do not tag as a production SDK release or advertise a standalone build kit.
6. Add the approved SDK and executable examples only after the release gates are satisfied.
